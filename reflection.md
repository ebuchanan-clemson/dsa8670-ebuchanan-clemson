One thing that I learned from the readings was how to use GitHub for version control and why that is important, especially when multiple people are working on something at the same time.
Version control can be helpful because you are able to make edits to your code or try new things, but if something does not work or you preferred things how they were before then you can
go back to a previous version. I thought that the website example in the readings was interesting. With version control, you can create the basic structure for your website and then add 
different features. If your code doesn't work or you liked how something looked before you made changes then you can simply go back to a previous version and redo everything. When multiple
people are working on a project then each person can create a branch and make changes without impacting the main until they commit the changes to the main.
